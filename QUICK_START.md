# 🚀 Quick Start - AI Agent Chatroom

## 30-Second Setup

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Set your API keys (choose at least one)
export OPENAI_API_KEY="your-key-here"
export ANTHROPIC_API_KEY="your-key-here"
export GEMINI_API_KEY="your-key-here"

# 3. Run the app
python app.py
```

Visit: **http://localhost:5000**

## What You Get

✅ **3 AI Providers**: OpenAI GPT, Anthropic Claude, Google Gemini  
✅ **6 Personas**: Researcher, Analyst, Creative, Skeptic, Pragmatist, Philosopher  
✅ **Dynamic Conversations**: Watch AI agents debate any topic  
✅ **Beautiful UI**: Modern, responsive design  

## First Steps in the App

1. **Add Agents** (left panel)
   - Click "+ Add Agent"
   - Name them (e.g., "Alice", "Bob")
   - Pick AI provider + model
   - Choose persona

2. **Start Chatting**
   - Enter a topic: "future of AI"
   - Set turns: 5
   - Click "🚀 Start Conversation"
   - Watch the magic happen! ✨

## Getting API Keys

### OpenAI
1. Go to: https://platform.openai.com/api-keys
2. Create account + add payment
3. Generate new secret key

### Anthropic
1. Go to: https://console.anthropic.com/
2. Sign up for access
3. Get API key from dashboard

### Google Gemini
1. Go to: https://makersuite.google.com/app/apikey
2. Sign in with Google account
3. Create API key
